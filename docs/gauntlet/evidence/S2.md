# S2 Catalog and savings (items S2-1 to S2-4)

Date: 2026-10-17. Reports run at about 15:00 UTC with `--until 2026-10-17`, so October is partial
and grows while this session runs.

## Built

- `internal/catalog/catalog.yaml` (embedded): 21 models and 3 plans. Every model has an https
  source and an as-of date; `Parse` rejects unknown fields, missing sources, bad tiers or data
  policies, duplicate names, negative or non-finite prices, and plans with no tier or a $0 tier.
  - Anthropic prices from Anthropic's pricing page, including 5-minute and 1-hour cache writes
    and Haiku 5.5's long-context price (prompts over 100,000 tokens, per request).
  - OpenAI prices from OpenRouter's model API (openai.com/api/pricing returned 403).
  - Open-weight models at OpenRouter list prices.
  - Plans: ChatGPT (Go $8, Plus $20, Pro $100/$200/$500, learn.chatgpt.com), OpenCode Go
    ($10/$40, opencode.ai/docs/go), Claude (Pro $20, Max "from $100", claude.com/pricing).
- `Model.Cost`: the only price function. Unknown model -> `ErrUnknownModel`; a needed price that
  is absent -> `ErrMissingPrice`; negative tokens or 1-hour writes above all writes ->
  `ErrBadUsage`. Never $0.
- `Model.CostAs`: counterfactual pricing with the same token split; labeled estimate.
- `Catalog.Savings`, `CheapestPerTier`, `Subs`; commands `inferencia savings [--as]` and
  `inferencia subs`, sharing one flag set with `measure`.
- Ledger: `Usage.CacheWrite1h` (Claude Code writes the 1-hour cache, priced at 2x input, not
  1.25x), `Totals.Add` exported so catalog reuses it instead of a copy.

## Findings

- F3: Flat plans are worth 25-31x their $20 price at your usage, if the plan's quota allows it.
  The ChatGPT plan carried $603 of gpt-6-astra tokens in half a month. This is the strongest
  number in the project so far, and it argues for subscription-first dispatch (E4, S5).
- F4: OpenCode Go is the weak plan for you: $33 of value in its best month, under $3 in others.
- F5: Price tables disagree. OpenCode's own table prices deepseek-v4-flash about 5x below
  OpenRouter's list price, and glm-5.2 about 2x above. Command Code's table matches OpenRouter
  exactly (muse-spark $2.73, deepseek-v4.1-flash $0.60). E1 needs a bill to say which is right.
- F6: Cache-read price drives model choice more than headline price. gpt-6-astra and
  claude-opus-5-5 differ 2.5x on input but 5x on cache reads, and 97% of tokens are cache reads.

## Adversarial review

Reviewer: fresh `ecc:go-reviewer` subagent. No BLOCKER, 2 MAJOR, 10 MINOR, 6 weak tests. It
spot-checked all 21 prices against their sources and found them correct.

| Finding | Fix |
| --- | --- |
| MAJOR: Haiku 5.5 over-100k price not modeled, so counterfactuals ran low silently | `long_context` block in the catalog; `PriceFor` picks it per call; test at the 100,000 boundary |
| MAJOR: dead error branches; an alternative's error would abort the report | `CostAs` fails only on invalid usage; unpriced usage is filed through one helper with its reason |
| `Cost` accepted negative or inconsistent tokens | `ErrBadUsage`, tested |
| Claude writes given only as a breakdown were dropped | `CacheWrite = max(top level, 5m + 1h)` |
| `Parse` accepted negative or NaN prices, empty or $0 tiers | validated, tested |
| UNPRICED header wrong for missing prices; zero-token models were noise | reason printed per model; zero-token usage skipped |
| Symmetric ±15% band hides Anthropic's tokenizer skew | footer cites Anthropic's "about 30% more tokens" |
| `AS RUN $` hid the harness's own cost | `HARNESS $` column added |
| Max $200 tier missing | footer: Max is listed only "from $100"; higher tiers lower the ratio |
| Partial month compared with a full month's price | month labeled "(partial)"; zero-time records skipped |
| CheapestPerTier is cherry-picked on the same data | footer says best case, quality not considered |
| DRY: duplicated unpriced block, name-based catalog flag, repeated catalog load | `Unpriced.file`, `withCatalog bool`, `loadPriced`, `flush` |
| Weak tests | exact-value regexes for the totals and subs rows; tests for missing-price filing, 5-minute fallback, long context, impossible usage, `Load` from a file, `--catalog` rejected by measure, and every tier pick |
