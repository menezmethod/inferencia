# S1 Measure (items S1-1 to S1-6)

Date: 2026-10-17.

## Built

- `internal/ledger`: one `Usage` record (Input = uncached input only; Output includes
  reasoning), `Window`, `Totals`, `Sum`, `Summarize`, `PartialError`.
- Four adapters, each a plain function returning `[]Usage`:
  - `ClaudeCode`: JSONL transcripts; dedup by message id across files (the copy with the most
    output wins); sidechain or `subagents/` path (relative to the root) means delegated.
  - `Codex`: session JSONL; running total = finished segments + current counter, so a counter
    reset adds instead of losing tokens; token events before the file's own `session_meta` are
    replayed history and ignored; model = last `turn_context` at or before Until.
  - `OpenCode`: `sqlite3 -readonly -json` with `.timeout 3000`, absolute path, and
    `json_valid(data)`; reads only `message` and `session`; `session.parent_id` means delegated.
  - `CommandCode`: JSONL usage lines; `*.checkpoints.jsonl` skipped; inputTokens includes
    cache reads.
- `Load` and `WriteReport`; `inferencia measure [--since --until --claude-dir --codex-dir
  --opencode-db --commandcode-dir]` in `cmd/inferencia/measure.go`. The server path is
  unchanged when no subcommand is given.
- Unreadable lines and files are counted and printed as warnings (`PartialError`), never
  dropped silently. Exit 1 when no source can be read, 2 on bad flags, 0 on `-h`.

## Finding F1: Claude Code deletes transcript history

The Claude count up to 2026-09-30 is 6,713, not 12,247. The transcripts now on disk
(358 files, down from 376 on 2026-09-30) cover only 23 days up to that date, starting
2026-07-03. Claude Code removes old transcripts on a retention schedule, so usage history
disappears from the source the ledger reads. The cache share still matches (98.1% vs 98.2%).
Consequence: a ledger that only reads live logs loses history. Two fixes, recorded as D5:
raise Claude Code's transcript retention (a user setting, not changed by the gauntlet), and
later persist normalized Usage records (tokens and model names only, no text).

## Adversarial review

Reviewer: fresh `ecc:go-reviewer` subagent with no context. It found 5 MAJOR and 10 MINOR
issues and 8 weak or missing tests. All MAJOR issues were reproduced by the reviewer and fixed:

| Finding | Fix | Test |
| --- | --- | --- |
| Symlinked root read as empty | `filepath.EvalSymlinks(root)` | "follows a symlinked root" |
| Bad lines dropped silently | `PartialError` counts them; Load warns and keeps records | Claude BadLines, measure stderr |
| Codex counter reset or fork | running total across segments; ignore events before own `session_meta` | "adds across a counter reset" |
| Codex model blank after `--since` | model tracked up to Until, not only inside the window | Since spec asserts Model |
| One corrupt OpenCode row kills the source | `json_valid(m.data)` in WHERE | m6 fixture row |

MINOR fixes: cross-file dedup keeps the most output; `subagents` check uses the relative path;
an unreadable file is counted and the walk continues; empty HOME reads nothing relative;
`-h` exits 0, stray arguments exit 2, no readable source exits 1; sqlite3 busy timeout and
absolute path; deterministic sort tie-breakers; negative tokens clamp to 0; partial cost shows
`*`; a row with no creation time is counted as unreadable; control characters are stripped from
printed names. Test fixes: the subagent fixture no longer sets `isSidechain`, so the path rule
is proven alone; Codex `Delegated=false`, Claude `--since` with a +02:00 offset, OpenCode
`--since`, `-` and `*` cost display, and the Command Code clamp now have specs. Duplicated
`total`/`sum` helpers became `ledger.Sum`; `WriteReport` uses one `row` helper; the
single-caller `keep` parameter was removed.

Rejected, with reason:
- Follow symlinked subdirectories: not followed on purpose, so a link loop cannot occur.
- `Usage.Time` and `Usage.Session` unused: S2 (savings by session) and E2 (replay) use them.
- OpenCode specs skip without sqlite3: GitHub's ubuntu runners ship sqlite3, so CI covers them.
- Whole lines held in memory: needed to decode a line; prefilters now skip decoding of
  irrelevant lines (golden run 7.7 s to 1.8 s).
